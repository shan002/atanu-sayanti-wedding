RSVP GOOGLE SHEET FIX

1. Open your Google Sheet.
2. Copy the spreadsheet ID from its URL:
   https://docs.google.com/spreadsheets/d/SPREADSHEET_ID/edit
3. Open Extensions > Apps Script.
4. Replace Code.gs with the Code.gs in this folder.
5. Paste the spreadsheet ID into:
   const SPREADSHEET_ID = '...';

TEST THE SHEET CONNECTION FIRST
6. In Apps Script, select function testWrite and click Run.
7. Authorize it when Google asks.
8. Your Google Sheet should now contain an RSVP tab and a Test Guest row.

DEPLOY
9. Deploy > New deployment > Web app.
10. Execute as: Me.
11. Who has access: Anyone (if available).
12. Deploy and copy the Web app URL ending in /exec.

TEST THE DEPLOYMENT
13. Open the /exec URL in a private/incognito browser.
    It should display:
    RSVP endpoint is live

CONNECT THE WEBSITE
14. In assets/config.js, set:
    sheetEndpoint: "YOUR_WEB_APP_URL_ENDING_IN_EXEC"

15. Test an RSVP from the website and verify a new row appears.

IMPORTANT
If you edit Code.gs after deploying, go to:
Deploy > Manage deployments > Edit > New version > Deploy

If your university Google Workspace account does not offer public "Anyone"
access, use a personal Google account for the RSVP sheet/script so external
wedding guests can submit without signing in.
